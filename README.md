# ChartAlive Terminal - Desktop Releases

Modern Multi-Broker Real-time Charting, Screening & Backfilling Desktop Terminal.

## Features
- **Zero-Config Real-Time Feeds**: Streaming live ticks for crypto, commodities, and forex via BiQuote & Delta Exchange out-of-the-box.
- **Embedded DuckDB Engine**: Analytical columnar database storing ticks, multi-timeframe OHLCV bars, and technical indicators.
- **Pre-configured Visual & SQL Screeners**: 20+ visual screeners and 7 SQL screeners included.
- **Single Intraday 4-Chart Grid**: Daily, 1H, 15m, 5m layout with direct TradingView launch buttons.
- **Multi-Broker Authentication**: Connect Fyers, Shoonya (Finvasia), AngelOne, Upstox with custom credentials in Terminal Settings.

## Getting Started
1. Download the release package.
2. Launch ChartAliveTerminal.exe.
3. Default watchlist starts cleanly with BTCUSD and XAUUSD.
